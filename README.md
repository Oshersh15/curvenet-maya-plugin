# Curvenet Maya Plugin

A Maya C++ plugin inspired by Pixar's *Character Articulation through Profile Curves* (De Goes et al., 2022).

## Project Overview

This project investigates Curvenets as a topology-independent rigging representation, where profile curves drive surface deformation and can be reused across different mesh topologies.

## Current Status

- Project setup completed
- Proof of concept completed
- Research and implementation phase in progress

## Technologies

- C++
- Autodesk Maya API
- CMake

## Reference

De Goes, F., Sheffler, W., & Fleischer, K. (2022). *Character articulation through profile curves*.
